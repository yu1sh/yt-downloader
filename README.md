# YT保存

YouTubeの動画と音声を保存できるサイトです。利用には、管理者から案内されたアカウントが必要です。

## 使い方

1. YouTubeの動画ページからリンクをコピーします。
2. YT保存にログインし、リンクを貼り付けて「動画を確認」を押します。
3. 保存したい内容を選び、「保存の準備を始める」を押します。
4. 準備が終わったら「この端末に保存」を押します。

ページを閉じても処理は続きます。あとから「保存履歴」を開くと、完成したファイルを保存できます。

## 簡単モード

最初に表示されるモードです。保存する内容を選ぶだけで使えます。

- 音声：MP3・320kbps
- 動画：MP4・最大720p

## 詳細モード

画質や形式を選びたいときに使います。

- 動画：MP4またはWebM、取得できる画質から選択
- 音声：MP3、M4A、Opusから選択
- MP3：128kbps、192kbps、320kbpsから選択

動画や音声の種類によって、表示される選択肢は異なります。

## 保存期間

完成したファイルは、準備ができてから24時間後に自動削除されます。必要なファイルは早めに端末へ保存してください。保存履歴は7日間表示されます。

## 利用上の注意

保存する動画や音声の利用権限を確認し、YouTubeの利用規約と著作権法に従って利用してください。プレイリスト、ライブ配信、字幕、動画の一部分だけの保存には対応していません。

## 困ったとき

リンクが正しいか確認し、少し時間をおいてからもう一度お試しください。ログインできない場合やアカウントが必要な場合は、管理者へ連絡してください。
